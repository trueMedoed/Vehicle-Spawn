# Workbench Debugging Guide

## Запуск Workbench

**Перед запуском ВСЕГДА проверяй**, не запущены ли процессы Workbench:

```bash
tasklist | grep -i ArmaReforgerWorkbench
```

Если процессы есть — убей их перед запуском (см. раздел ниже).

Всегда запускай `wb_launch` с таймаутом 15 секунд вместо дефолтных 60:

```
wb_launch(gprojPath: "...", timeoutSeconds: 15)
```

Обычно проблемы в коде скриптов, и не надо минуту ждать — если за 15 секунд не подключился, значит что-то не так.

## wb_launch зависает — что делать

Если `wb_launch` висит в статусе "Running..." и не подключается за 15 секунд — значит Workbench запустился, но EnfusionMCP bridge не отвечает.

**Причина**: обычно ошибка компиляции в скриптах проекта блокирует загрузку EnfusionMCP handler addon.

**Решение**:

1. Убить процессы Workbench:
   ```bash
   taskkill //F //IM ArmaReforgerWorkbenchSteamDiag.exe
   ```
   **ВАЖНО**: использовать `//F` и `//IM` (двойной слэш), а не `/F` и `/IM` — bash интерпретирует одиночный слэш как путь!

2. Проверить логи компиляции и исправить ошибки в коде

3. Попробовать снова запустить через `wb_launch`

## Обновление списка плагинов

После изменения `WorkbenchPluginAttribute`, базового класса плагина или его категории в Workbench нужно выполнить:

```text
Plugins → Settings → Reload WB Scripts
```

Эта команда одновременно перекомпилирует скрипты, обновляет регистрацию плагинов и добавляет переименованные или новые пункты в меню **Plugins** без полного перезапуска Workbench. Отдельный вызов `wb_reload(target: "scripts")` перед ней не нужен.

## Запуск плагинов World Editor

При вызове `wb_execute_action` указывай путь от `Plugins`, например:

```
Plugins,<название плагина>
```

Если `wb_execute_action` вернул `false`, сначала проверь точность пути и доступность пункта в текущем редакторе. Сам по себе этот результат не означает ошибку компиляции скриптов.

## Типичные симптомы

- `wb_launch` показывает "Running..." больше 15 секунд
- NET API не отвечает (bridge не подключается)
- В системе есть процессы ArmaReforgerWorkbenchSteamDiag.exe, но соединение не устанавливается

## Решение

Убить процессы и перезапустить. Если проблема повторяется — проверить логи компиляции, там почти наверняка ошибка в коде скриптов.
