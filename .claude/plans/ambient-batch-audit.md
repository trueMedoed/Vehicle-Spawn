# Пакетный аудит ambient-точек

- Использовать существующий одиночный аудит и его итоговые данные.
- Список сценариев в профиле Workbench, стартовый набор Cain/Eden.
- Последовательная загрузка через SetOpenedResource с проверкой GetWorldPath; остановка при отказе/несовпадении.
- Нумерованные сводные отчёты без перезаписи; привязка подробных логов к миру.
- Test-only. Сборка и поведение загрузчика требуют проверки в Workbench.
