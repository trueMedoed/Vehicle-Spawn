## Summary

Смотрите примеры техники у ambient-точек в Workbench и находите проблемы фильтра, свободного места и размещения до запуска миссии.

## Description

Ambient Vehicle Spawn Diag добавляет в Workbench диагностику ванильных точек появления ambient-техники в Arma Reforger.

Это инструмент для создания миссий и проверки настроек. Аддон не заменяет ванильную систему появления ambient-техники и не добавляет отдельную систему появления техники.

Возможности
• Запрещает размещение точки появления ambient-техники, когда текущая настройка мира её не поддерживает.
• Проверяет, что доступен ровно один редактируемый GameMode.
• Предупреждает, когда слой GameMode заблокирован.
• Проверяет, что в Test Game Flags у GameMode включён Spawn Vehicles.
• Показывает полупрозрачную голограмму примера техники у каждой загруженной ambient-точки. Пример выбирается по фильтру точки и справочнику габаритов, но не предсказывает конкретную технику при появлении.
• Оставляет голограмму белой, если явная проблема не найдена, и окрашивает её в красный при проблеме фильтра, каталога, поиска свободного места или пересечении показанных примеров техники. Если подходящих кандидатов нельзя использовать, пример той же фракции явно помечается как запасной.
• Показывает над каждой голограммой фракцию точки её цветом. Голограмма следует за перемещением и поворотом точки.
• Отмечает статические физические объекты ориентированными красными каркасами при пересечении области появления. Пересечения со статическими объектами и областями других точек показываются как предупреждения с координатами; отсутствие свободной позиции — отдельная ошибка. Предупреждения только об областях появления не окрашивают голограмму, а пересечение габаритов показанных машин окрашивает. Оно не доказывает неудачу игрового спавна.
• Команды Next и Toggle vehicle hologram находятся в Plugins → [ME] Vehicle Spawn → Preview.
• Показывает ошибки конфликта меток и пустого результата фильтра отдельными сообщениями над точкой. При пустом результате указаны настроенные include/exclude; недоступный каталог отмечается предупреждением.
• Отображает над точкой её настроенные метки: включающие — своими цветами, исключающие — красным, ALL — когда список пуст. Две метки пассажирской вместимости объединяются в одну строку через запятую.
• Содержит worlds/ME_TestWorld.ent с корректными и намеренно некорректными примерами для проверки диагностики.
• Проверяет наличие FactionManager в мире.
• Проверяет принадлежность к фракции у добавляемых префабов точек появления ambient-техники.
• Запрещает размещение, когда точке появления нужна фракция, недоступная в FactionManager мира.

Важные замечания
• Визуальные проверки и пересечения границ объектов служат диагностикой редактора и не гарантируют успешное появление техники во время игры.
• Аддон рассчитан на ванильные точки появления ambient-техники Arma Reforger.
• Проверялся только с ванильным содержимым игры.
• Совместимость с другими модами не гарантируется, особенно с модами, переопределяющими SCR_AmbientVehicleSpawnPointComponent, SCR_AmbientVehicleSystem или коллбэки размещения World Editor.
• Некоторые слои в ME_TestWorld намеренно содержат конфликты и некорректные настройки. Это демонстрационные случаи, а не готовое содержимое для миссий.

Как использовать
1. Откройте свой мир в Workbench.
2. Настройте ровно один редактируемый GameMode.
3. Включите Spawn Vehicles в Test Game Flags.
4. Добавьте в мир FactionManager и настройте нужные фракции.
5. Разместите ванильный префаб Ambient Vehicle Spawnpoint.
6. По визуальным индикаторам и диалогам с предупреждениями исправьте размещение или настройку.
7. Для ручной проверки текущего мира откройте Workbench Plugins и запустите «Check ambient vehicle spawning».

Проверка существующих сценариев Conflict
Мод можно использовать и для проверки существующих сценариев Conflict. Откройте сценарий в World Editor с подключённым модом — визуальные подсказки помогут найти проблемные метки, пересечения областей появления и возможные препятствия рядом с точками техники. Запускать игровой режим для просмотра подсказок не требуется.
