## Повторная проверка

Сохранить работу в World Editor, выполнить Reload WB Scripts и запустить Batch audit ambient vehicle scenarios для тех же семи миров. Затем из корня проекта сравнить новый отчёт, указав фактическую версию игры из console.log:

```powershell
.\tools\Compare-AmbientAudit.ps1 `
  -Report "$env:USERPROFILE\Documents\My Games\ArmaReforgerWorkbench\profile\ME_AmbientAuditBatch_7.txt" `
  -GameVersion "НОВАЯ_ВЕРСИЯ" -ErrorsOnly `
  -Output "$env:TEMP\AmbientAudit-errors-comparison.md"
```

Для полной проверки убрать ErrorsOnly. Параметры Report и Baseline принимают общий TXT или каталог файлов по мирам. Эталон по умолчанию — worlds рядом с этой сводкой. Скрипт сравнивает готовые отчёты и не запускает Workbench.

Сравниваются счётчики, покрытие и замечания по координатам, короткому имени prefab, причине, уровню, объекту и координатам пересекающейся точки. Runtime ID не участвуют. Координаты сравниваются точно. Перемещение может выглядеть как исчезновение старого замечания и появление нового. Изменение алгоритма аудита следует учитывать отдельно от обновления игры. Прерванные отчёты отклоняются; файлы errors требуют ErrorsOnly.

Для следующей версии игры сохранять такую же структуру: Summary.md, worlds/*.txt и errors/*.txt. Полный pointPrefabPath не выводится. Одинаковые короткие имена prefab в разных каталогах не различаются.
