### Доработки

- [x] В Test голограмма выбирает prefab из `ME_VehicleBoundsSnapshot.conf`: для каждой пары «фракция/VEHICLE_* метка» snapshot хранит модель с наибольшей фактической площадью (ширина × длина), с высотой и путём prefab как разрешением равенства. При нескольких подходящих типах сначала выбирается самый большой тип. Выбранный prefab сверяется с текущим фильтром точки; если он исключён, fallback остаётся в этом же типе (например, невооружённый Huey вместо грузовика для US ALL - TRAIT_ARMED). `Next` перебирает всех кандидатов. Bounding Box и стрелка больше не рисуются. Перебор мешей при выделении удалён. Требуется проверка в Workbench.
- [x] В Test голограмма остаётся стандартной белой, если явных ошибок нет. Ошибка фильтра, отсутствие свободного места и невозможность проверить кандидатов дают красный цвет.
