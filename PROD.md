# Production addon

`ME_Vehicle_Spawn` содержит editor-only голограммы примеров техники, метки фракций и фильтра, маркеры статических препятствий и Workbench warning plugin для ambient vehicle spawn points. Расширенная runtime-инструментация Test сюда не переносится; существующая диагностика пустого результата фильтра в Update сохранена.

## Требования

Демонстрационный мир `worlds/ME_TestWorld.ent` должен запускаться с GameMode, содержащим `SCR_FactionManager` и включённым `EGameFlags.SpawnVehicles`. В мире должна присутствовать ambient vehicle spawn point.

## Проверка

В Edit mode запустите Plugins → `[ME] Vehicle Spawn` → `Check ambient vehicle spawning`, проверьте preflight guards и голограммы всех загруженных точек. Переместите и поверните точку: голограмма и метка фракции должны следовать за ней без дубликатов. Команды Next/Toggle находятся в `[ME] Vehicle Spawn/Preview`. Затем войдите в Game mode и проверьте базовый spawn flow.

Голограмма — редакторский пример и предварительная проверка, а не обещание runtime spawn.

Production нельзя загружать одновременно с `ME_Vehicle_Spawn_Test`.

Пользователь подтвердил проверку схемы 6 в production Workbench 05.10.2026.


Пересечения со статическими объектами проверяются по локальным границам модели с мировым transform (OBB); препятствия отмечены ориентированным красным каркасом. Пересечение OBB и областей двух точек — WARNING с просьбой перепроверить размещение. Если пересекаются объёмные границы самих показанных голограмм, обе становятся красными; это визуальное предупреждение, а не доказательство неудачного runtime spawn. Неудачный поиск свободной позиции — отдельный ERROR и красная голограмма. Пользователь подтвердил проверку голограмм и пассажирских меток в production Workbench 05.10.2026.
